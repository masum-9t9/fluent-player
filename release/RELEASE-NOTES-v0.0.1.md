# Fluent Player v0.0.1

A first public build of Fluent Player: a native Windows video player with a dark interface, orange accents, and mpv-powered playback.

## Downloads

- **FluentPlayer-v0.0.1.exe** — application executable. Download it together with `libmpv-2.dll` from the assets below and keep both files in the same folder.
- **FluentPlayer-v0.0.1-portable.zip** — ready-to-run portable folder containing the application, playback runtime, and quick-start instructions. Extract the ZIP and launch `FluentPlayer.exe`.

> The portable ZIP is the easiest option. This release is for 64-bit Windows 10 and Windows 11. It is a portable distribution, not a setup wizard.

## Highlights

- Open video files or scan a media folder; use Library, Recent, History, Favorites, and Playlist views.
- Playback controls include seeking, previous/next, frame stepping, subtitles and audio tracks, repeat, and A–B loop.
- Picture-in-picture, screenshots, hardware-decoding toggle, playback speed from 0.25× to 4×, and volume up to 200%.
- Adjust brightness, contrast, saturation, and gamma; turn on reduced motion in settings.
- Custom dark UI with orange accents and Fluent Player branding.

## Install / run

1. Download the portable ZIP asset below.
2. Extract the ZIP to a folder of your choice.
3. Run `FluentPlayer.exe`. Leave `libmpv-2.dll` in the same folder.

No installer is needed. The app and its runtime stay in the extracted folder.

## Notes

- Windows x64 only for this release.
- `libmpv-2.dll` is required for media playback and is included in the portable ZIP.
- Review `THIRD-PARTY-NOTICES.md` in the portable package for mpv runtime provenance and licensing notes.
- This is version 0.0.1; please report issues with the media format, Windows version, and steps to reproduce.
