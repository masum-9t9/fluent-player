# Fluent Player v0.0.1 release files

- `FluentPlayer-v0.0.1.exe` is the regular Windows application executable. Keep `libmpv-2.dll` beside it to enable playback.
- `portable/` and `FluentPlayer-v0.0.1-portable.zip` contain the same app and runtime as a self-contained folder package; unzip and run `FluentPlayer.exe`.
- `THIRD-PARTY-NOTICES.md` records the included mpv runtime provenance and licensing note.

Target: Windows 10/11 x64. The portable archive is not an installer and does not write application files into Windows installation directories.
